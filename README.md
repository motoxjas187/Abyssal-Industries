# Abyssal Industries — Android shell

A full-screen Android app that shows the game page in `app/src/main/assets/index.html`.

- Every push builds a debug APK. Open the **Actions** tab, pick the latest run, and download **abyssal-industries-debug-apk**.
- To update the game, replace `app/src/main/assets/index.html` and push.
- This is a debug build for testing. A Play Store release needs a signed app bundle.
